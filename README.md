# AI Study

Source-linked study guides on AI agents, evaluation, prompt optimization and recursive self-improvement.

For developers, researchers and learners who want to understand how AI systems can improve through measured feedback. The material connects public research to practical experiment design, with framework comparisons and fictional exercises.

**Start here:** [Study guide](studies/recursive-self-improvement/README.md) · [Framework comparison](studies/recursive-self-improvement/frameworks.md) · [Practice exercise](studies/recursive-self-improvement/experiment-design.md) · [Primary sources](studies/recursive-self-improvement/reading-list.md)

## How to use these notes

Documented framework behavior is linked to primary sources. Suggested designs and fictional examples are identified as such. The repository contains educational notes, not benchmark results, an executable optimizer or an endorsement of a particular framework.

Framework interfaces and availability can change. Check the source-review date and current official documentation before implementing an experiment. A better optimization score is useful only when the evaluation measures the intended behavior.

For dated study editions, see the [repository releases](https://github.com/Ai11-Consulting-GmbH/ai-study/releases).

Corrections, clearer explanations and new public-source studies are welcome.
